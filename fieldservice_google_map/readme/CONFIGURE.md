To configure this module, you need to:

1. Install and configure `base_google_map` / `web_view_google_map` (Google Maps
   API key and libraries) as documented in OCA/geospatial.
2. Go to **Field Service > Configuration > Stages**.
3. Optionally set a **Custom Color** on each stage (used by related marker
   color fields; map marker icons use named colors via the view `colors`
   attribute).
